How to play: tap an empty cell or one of your own to add an orb. Critical mass = number of neighbours: corners 2, edges 3, centre 4. At critical mass a cell explodes, sending one orb to each neighbour and converting them to your colour. Chains continue until stable. Eliminate everyone else to win.
Online: enter a Room Code, then one player taps Host Room and the others Join with the same code (2–6 players). Host presses Start once everyone is ready.
